# website-creation

**KLIRSTUDIO** — Jasa Pembuatan Website Berkelas & Mesin Penjualan Bisnis.

## Tech Stack & Architecture
- **Structure**: Semantic HTML5 with accessibility best practices.
- **Styling**: Vanilla CSS with custom design system, glassmorphism, responsive grid, and fluid typography.
- **Interactions**: Vanilla JavaScript (Hero dynamic shimmer rotator, 3D interactive coverflow, neural constellation canvas, FAQ accordion, package toggles).
- **Typography**: Google Fonts (Instrument Sans, Playfair Display Italic, JetBrains Mono, Outfit, Syne).

## Quick Start
To run locally:
```bash
# Using live-server or standard local dev server
npx live-server --port=3000
```
Or double-click `start-website.bat` on Windows.
